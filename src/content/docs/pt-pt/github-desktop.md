description: Clona um repositório, faz commits e envia para o GitHub com o GitHub Desktop.
---

O GitHub Desktop é uma forma visual de usar o Git. É útil quando queres a mesma rotina sem escrever todos os comandos.

## 1) Instala o GitHub Desktop

Descarrega-o no GitHub e inicia sessão com a mesma conta que usas no GitHub.

![Início de sessão do GitHub Desktop](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png)

## 2) Clona um repositório

- abre **File → Clone repository**
- escolhe um repositório do GitHub
- escolhe uma pasta local
- clica em **Clone**

![Clonar um repositório no GitHub Desktop](https://github.githubassets.com/images/modules/site/icons/octicons/repo.svg)

## 3) Faz uma alteração

Edita um ficheiro local e depois volta ao GitHub Desktop.

Vês:

- ficheiros alterados
- uma vista da diferença
- uma caixa para escrever a mensagem do commit

## 4) Faz commit e envio

1. escreve uma mensagem curta como `Add learning goals`
2. clica em **Commit to main** ou **Commit to <branch>**
3. clica em **Push origin**

![Fluxo de commit no GitHub Desktop](https://github.githubassets.com/images/modules/site/icons/octicons/git-commit.svg)

## 5) Cria um ramo

- clica no nome do ramo atual
- escolhe **New branch**
- dá-lhe um nome claro, por exemplo `fix/readme-link`
- começa a trabalhar aí

## 6) Abre um pull request

Quando o ramo estiver pronto:

- clica em **Create pull request**
- revê as alterações no GitHub
- integra o PR

![Fluxo de pull request no GitHub Desktop](https://github.githubassets.com/images/modules/site/icons/octicons/git-pull-request.svg)

## Quando vale a pena usar

O GitHub Desktop é útil quando queres:

- ver diferenças visualmente
- seguir um fluxo de commit simples
- fazer menos passos no terminal

**Experimenta:** clona o teu projeto, faz uma pequena edição, faz commit e envia para o GitHub.
