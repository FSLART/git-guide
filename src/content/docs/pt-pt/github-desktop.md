O GitHub Desktop dá-te um fluxo visual de Git. É útil quando queres criar um repositório, rever alterações, fazer commits e enviar para o GitHub sem escrever todos os comandos.

## Começa com o fluxo oficial

O caminho recomendado para iniciantes é simples:

1. Instala o GitHub Desktop
2. Inicia sessão no GitHub
3. Cria um novo repositório ou começa o tutorial
4. Faz uma alteração pequena
5. Faz commit e envia para o GitHub
6. Abre um pull request

## 1) Instala e inicia sessão

Instala o GitHub Desktop na página oficial e inicia sessão com a mesma conta do GitHub que usas nos teus projetos.

Se ainda não tiveres repositórios, vais ver a vista “Let’s get started!”.

![Captura da vista “Let’s get started!” do GitHub Desktop](https://docs.github.com/assets/images/help/desktop/lets-get-started.png)

## 2) Cria um repositório

Podes escolher entre:

- **Create a Tutorial Repository...**
- **Create a New Repository on your Hard Drive...**

Se quiseres um primeiro exercício rápido, escolhe o tutorial. Ele mostra o básico: ramo, edição, commit, push e pull request.

Se criares um novo repositório manualmente, preenche:

- o nome
- uma descrição opcional
- a pasta local
- se queres inicializar com um README
- opções de gitignore e licença, se forem relevantes

Depois clica em **Create repository**.

## 3) Explora a aplicação

Quando o repositório abrir, vais ver a barra do repositório no topo.

![Captura da barra do repositório no GitHub Desktop](https://docs.github.com/assets/images/help/desktop/explore-github-desktop.png)

As partes principais são:

- **Current repository**
- **Current branch**
- **Publish repository** quando o repositório ainda é só local
- as vistas **Changes** e **History** na barra lateral

## 4) Faz uma alteração e guarda um commit

Abre o teu editor a partir da aplicação, edita o `README.md` e guarda as alterações.

Volta ao GitHub Desktop e entra na vista **Changes**.

![Captura da vista Changes com um README e a caixa de commit](https://docs.github.com/assets/images/help/desktop/viewing-changes.png)

Escreve um resumo curto do commit, por exemplo:

```text
Add project purpose
```

Depois clica em **Commit to BRANCH NAME**.

![Captura da área de mensagem do commit no GitHub Desktop](https://docs.github.com/assets/images/help/desktop/commit-message.png)

## 5) Publica no GitHub

Quando o repositório estiver pronto, clica em **Publish repository**.

![Captura do botão Publish repository](https://docs.github.com/assets/images/help/desktop/publish-repository.png)

Depois escolhe as definições do repositório remoto e clica em **Publish Repository**.

## 6) Envia o teu commit

Depois do primeiro commit, clica em **Push origin**.

![Captura do botão Push origin](https://docs.github.com/assets/images/help/desktop/push-to-origin.png)

Isto envia o teu commit local para o repositório no GitHub.

## 7) Abre um pull request

Quando o teu ramo estiver pronto, usa o fluxo do GitHub Desktop para abrir um pull request, rever as alterações e depois integrá-las no GitHub.

Também podes ver o repositório no GitHub com **View on GitHub**.

![Captura das sugestões do repositório e da ação View on GitHub](https://docs.github.com/assets/images/help/desktop/available-actions.png)

## Por que é útil

O GitHub Desktop é bom para:

- principiantes que querem um fluxo visual
- repositórios pequenos e exercícios de aprendizagem
- rever diferenças antes de fazer commit
- manter o fluxo de Git simples

**Experimenta:** cria um repositório pequeno no GitHub Desktop, adiciona uma linha ao README, faz commit e envia para o GitHub.
