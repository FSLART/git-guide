## Menos mistério. Mais confiança.

Não precisas de saber programar para aprender Git. Traz um editor de texto e alguma curiosidade. Vamos começar pelo básico e criar bons hábitos pelo caminho.

### O teu projeto de prática

Ao longo do guia, vais criar o **my-first-repo**, um pequeno diário de aprendizagem com ficheiros de texto simples. Sem aplicações para configurar. Sem conhecimentos de programação. Cada lição inclui um exercício e uma forma de confirmar o resultado.

Começa por [O que é o Git?](./introduction/) ou mantém a [referência de comandos](./cheat-sheet/) por perto. Usa as bandeiras no menu de idiomas para alternar entre português e inglês em qualquer altura.
