## A little less mystery. A lot more confidence.

You don’t need to be a programmer to learn Git. Bring a text editor and a little curiosity. We’ll start with the basics and build good habits along the way.

### Your practice project

Throughout the guide, you’ll build **my-first-repo**, a small learning journal made of plain text files. No application setup. No coding prerequisites. Each lesson includes something to try and a way to check your work.

Start with [What is Git?](./introduction/), or keep the [command cheat sheet](./cheat-sheet/) nearby. Use the flags in the language menu to switch between English and Portuguese at any point.
