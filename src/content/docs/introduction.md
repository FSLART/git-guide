Git tracks versions of your files.

## The quick idea

- Your folder: working directory
- Git: local history
- GitHub: remote copy and collaboration space

## Git vs GitHub

Git is the tool. GitHub is the website that hosts repositories.

Use Git to:

- save work
- try an idea safely
- review changes before sharing them

Use GitHub to:

- back up your repo online
- share code with others
- open pull requests

## Three places to remember

1. Working directory
2. Staging area
3. Repository history

## Start your project

```bash
mkdir my-first-repo
cd my-first-repo
git init
```

This creates a Git repository. You are ready for the next step.
