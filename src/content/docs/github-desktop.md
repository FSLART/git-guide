---

GitHub Desktop is a visual way to use Git. It is great when you want the same workflow without typing every command.

## 1) Install GitHub Desktop

Download it from GitHub and sign in with the same account you use on GitHub.

![GitHub Desktop sign in](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png)

## 2) Clone a repository

- open **File → Clone repository**
- choose a repo from GitHub
- choose a local folder
- click **Clone**

![Clone a repository in GitHub Desktop](https://github.githubassets.com/images/modules/site/icons/octicons/repo.svg)

## 3) Make a change

Edit a local file, then return to GitHub Desktop.

You will see:

- changed files
- a diff preview
- a commit box with a message

## 4) Commit and push

1. write a short message like `Add learning goals`
2. click **Commit to main** or **Commit to <branch>**
3. click **Push origin**

![Commit flow in GitHub Desktop](https://github.githubassets.com/images/modules/site/icons/octicons/git-commit.svg)

## 5) Create a branch

- click the current branch name
- choose **New branch**
- name it clearly, for example `fix/readme-link`
- start working there

## 6) Open a pull request

When the branch is ready:

- click **Create pull request**
- review the changes on GitHub
- merge the PR

![Pull request flow in GitHub Desktop](https://github.githubassets.com/images/modules/site/icons/octicons/git-pull-request.svg)

## Best use

GitHub Desktop is useful when you want:

- visual diffs
- a simple commit flow
- fewer command-line steps

**Try it:** clone a project, make a small edit, commit it, and push it.
