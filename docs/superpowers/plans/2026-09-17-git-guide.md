# Bilingual Git Guide Implementation Plan

**Goal:** Deliver the approved beginner guide in English and pt-PT, ready for GitHub Pages.

**Architecture:** Static Astro site with Starlight providing documentation navigation and search. Markdown lessons share slugs across languages. One custom language component builds base-aware counterpart URLs.

**Tech Stack:** Astro, Starlight, TypeScript, CSS, Node test runner, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-17-git-guide-design.md`

## Global constraints

- English default and European Portuguese (`pt-PT`).
- Clickable flags preserve the lesson and support keyboard navigation.
- Work at the `/git-guide/` GitHub Pages base path.
- Complete beginner lessons, exercises, safe examples, and sources.
- Work in the provided empty project; no existing implementation to preserve.

## Tasks

- [ ] 1. Configure Astro/Starlight (`package.json`, `astro.config.mjs`, `src/content.config.ts`, `tsconfig.json`). Install compatible dependencies for the available Node version.
- [ ] 2. Add `tests/language.test.mjs` with literal expectations for switching both directions at root and project base paths. Run it before implementing `src/lib/language.mjs`; then build the accessible `src/components/LanguageSelect.astro` and local flag SVGs.
- [ ] 3. Add landing pages, styling, matching English/Portuguese lessons and UI translations under `src/content/`. Use explicit review steps before destructive Git operations.
- [ ] 4. Add `.github/workflows/deploy.yml` and README with setup, preview, translation maintenance and Pages instructions.
- [ ] 5. Run unit tests, Astro checks, production build and `scripts/verify-build.mjs` to inspect language counterparts and all local links/assets. Preview in a browser at desktop/mobile, test the flags, search, themes and lesson navigation. Fix any defects and report verification evidence.

## Acceptance checks

`npm test`, `npm run check`, `npm run build`, and `npm run verify` must pass. `/git-guide/commits/` must link to `/git-guide/pt-pt/commits/` and back. Each lesson must have a real translated counterpart. Publishing is configured but is not claimed until a remote deployment succeeds.
